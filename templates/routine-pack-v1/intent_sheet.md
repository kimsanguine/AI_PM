# intent_sheet.md

> 루틴팩 v1. 작업 하나(또는 루틴 하나)에 한 장. AI에게 시키기 전에 채웁니다.
>
> 의도, 제약, 정지 규칙, 휴먼 체크포인트가 한 장에 묶여 있어야 벽과 브레이크가 같은 자리에서 작동합니다.
> 플레이북 본문은 4번을 "정지 규칙", 6번을 "휴먼 체크포인트"로 부릅니다. 번호를 바꾸지 마세요.

## 2. 결과 정의 (Outcome)

- 결과: [예: 장바구니에서 결제까지 3클릭 안에 도달.]
- 작업 단위: (a) [ ] (b) [ ] (c) [ ]

## 3. 제약 (Constraints)

건드리지 말 것.

- [예: 현재 디자인 시스템 유지. 외부 라이브러리 추가 금지.]

## 4. 정지 규칙 (Stop Rules)

언제 멈출지. 아래 4가지 중 내 상황에 맞는 1~2개를 남기고 수치로 적습니다.

| 조건 | 행동 |
|---|---|
| 같은 오류 [3]회 반복 | 정지하고 사람에게 보고 |
| 변경 파일 [10]개 초과 | 정지하고 사람에게 보고 |
| 토큰 사용 [30K] 초과 | 정지하고 사람에게 보고 |
| 본 작업과 무관한 영역 수정 시작 | 정지하고 사람에게 보고 |

## 5. 평가 지표

끝났는지 어떻게 확인하는가.

- [예: 직접 클릭해서 결제 완료 화면이 뜨면 OK.]
- 관련 `feature_list.json` 항목: [F-000]
